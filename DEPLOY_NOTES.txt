MEGA -> Telegram bot update

Download architecture:
- mega-public-client: public folder metadata and file-key extraction only.
- megadl (megatools): actual per-file downloads.
- Pyrofork: Telegram uploads.
- FFmpeg/ffprobe: media inspection, thumbnailing, remuxing and splitting.

Important:
1. Deploy with the included Dockerfile so the megatools package (megadl binary) is installed.
2. Keep mega-public-client==0.1.1 in requirements.txt; it is still used for metadata.
3. Whole-folder fallback is intentionally disabled. It can require the full folder size on Railway's ephemeral disk.
4. Initial conservative variables:
   PARALLEL_DL=2
   PARALLEL_UL=1
   DISK_LIMIT_GB=500
   BUFFER=2
5. DISK_LIMIT_GB is only a logical scheduling ceiling; it does not increase actual Railway disk capacity.
6. This code has passed Python syntax compilation. A live MEGA download test must still be performed on Railway.
